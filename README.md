# 📱 VisuALGO – Sorting Algorithms Visualizer

**VisuALGO** is an Android mobile application designed to visually demonstrate the workings of six fundamental sorting algorithms. Through dynamic animations, users can observe each step of the sorting process, making it an effective educational tool for students and enthusiasts aiming to deepen their understanding of algorithmic concepts.

## 🔍 Visualized Sorting Algorithms

- **Bubble Sort**
- **Selection Sort**
- **Insertion Sort**
- **Merge Sort**
- **Quick Sort**
- **Heap Sort**

## 🎯 Features

- Individual visualization screens for each algorithm  
- Step-by-step execution or automated playback  
- Adjustable animation speeds (slow, medium, fast)  
- Generation of random arrays for sorting demonstrations  
- Intuitive and user-friendly interface

## 🛠️ Built With

- **Kotlin** – for Android application development  
- **Android SDK**  
- **Canvas API** – for custom animations  
- **MVVM Architecture** – ensuring a clean separation of concerns

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/bestamibakir/VisuALGO.git
   ```

2. **Open the project in Android Studio.**  
3. **Ensure that all necessary SDKs and dependencies are installed.**  
4. **Run the application on an emulator or a physical Android device.**

## 📚 Project Purpose

This project was initiated with the aim of developing a mobile application that visualizes six well-known sorting algorithms.  
By providing a step-by-step observation of how these algorithms operate, the application serves as an interactive and instructive resource, particularly beneficial for students and individuals seeking to grasp the fundamentals of sorting algorithms.
